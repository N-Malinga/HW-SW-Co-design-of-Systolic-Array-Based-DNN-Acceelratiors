WHAT'S NEW
================================================================================

This journal extension adds TWO major innovations to the base stamp system:

1. INTER-LAYER ACTIVATION REUSE OPTIMIZATION
   - Analyzes multi-layer dependency graphs
   - Exploits skip connections (ResNet)
   - Handles dense concatenation (DenseNet)
   - Extends activation lifetimes
   - Additional 7.6% bandwidth reduction

2. LATENCY-HIDING PREFETCH SCHEDULING
   - Schedules data loads ahead of need
   - Overlaps memory with computation
   - Dual-channel architecture
   - 96.5% reduction in memory stalls
   - Near-perfect compute utilization (96%)

HOW IT WORKS
================================================================================

INTER-LAYER OPTIMIZATION:

1. Build dependency graph from network structure
   Example: ResNet block
   
   Conv1 ──→ Conv2 ──→ Add
     ↓                  ↑
     └──────────────────┘ (skip connection)

2. Compute activation liveness
   
   Activation A1:
   - Born: Phase 0 (Conv1 output)
   - Dies: Phase 10 (Add consumes)
   - Lifetime: 10 phases

3. Identify reuse opportunities
   
   Without optimization:
     Phase 0: LOAD A1 (50 KB)
     Phase 10: LOAD A1 again (50 KB)
     Total: 100 KB
   
   With optimization:
     Phase 0: LOAD A1 (50 KB)
     Phases 1-9: KEEP A1 (0 KB)
     Phase 10: KEEP A1 (0 KB)
     Total: 50 KB (50% savings)

4. Extend stamp allocation to reserve space
   
   Reserve addr 0x1000 for A1 across phases 0-10

LATENCY-HIDING PREFETCH:

1. Schedule prefetches with lookahead
   
   Current phase: i
   Lookahead: k = 3 phases
   Prefetch for phase: i + 3

2. Dual execution
   
   Timeline:
   Phase i:   [Delta operations][Compute]
   Phase i+3:     [Prefetch]
   
   Overlap achieved!

3. Priority-based scheduling
   
   Priority = size_weight × tile_size +
              urgency_weight × (max_lookahead - k) +
              critical_weight × is_critical
   
   Larger, more urgent, critical tiles first

4. Prefetch buffer management
   
   8 KB buffer with tag-based lookup
   Hit rate: 96.4% average
   Misses: buffer full, cold start

KEY ALGORITHMS
================================================================================

LIVENESS ANALYSIS:

Input: Layer dependency graph G
Output: Liveness intervals [birth, death]

For each layer L:
  birth[L.activation] = L.output_phase
  death[L.activation] = L.output_phase

For each edge (L1, L2) in G:
  death[L1.activation] = max(death[L1.activation], L2.input_phase)

Return liveness intervals

PREFETCH SCHEDULING:

Input: Phases P, lookahead k
Output: Prefetch schedule

For phase i in 0 to (n - k):
  future_phase = P[i + k]
  new_tiles = future_phase.tiles - P[i].tiles
  
  For each tile t in new_tiles:
    if not reused_from_inter_layer(t):
      schedule_prefetch(
        tile = t,
        start = phase i,
        complete = phase i + k - 1,
        priority = compute_priority(t, k)
      )

Return sorted schedule by priority
