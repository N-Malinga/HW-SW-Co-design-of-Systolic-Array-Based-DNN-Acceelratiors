KEY RESULTS
================================================================================

✓ 83.6% off-chip bandwidth reduction
✓ 91.8% memory management cycle reduction  
✓ 30% hardware logic reduction
✓ Deterministic, predictable performance
✓ No hash tables or tag matching required

Example layer (Conv-16-32):
  • 128 execution phases
  • 381 delta operations
  • 52% KEEP (free), 15% MOVE (on-chip), 33% LOAD (off-chip)
  • Compilation time: 0.15 seconds

1. UNDERSTAND THE APPROACH
   $ cat IMPLEMENTATION_SUMMARY.md

2. COMPILE A LAYER
   $ python3 stamp_compiler.py

   $ python3 stamp_analyzer.py

================================================================================
ARCHITECTURE OVERVIEW
================================================================================

COMPILER (Offline):
  DNN Layer Config
        ↓
  Phase Generator → Creates execution phases
        ↓
  Stamp Allocator → Assigns on-chip addresses
        ↓
  Delta Analyzer → Identifies KEEP/MOVE/LOAD ops
        ↓
  Metadata JSON → Hardware instructions

HARDWARE (Runtime):
  Metadata RAM (256 entries)
        ↓
  Controller FSM → Executes delta operations
        ↓
  Scratchpad (16 KB) ↔ Off-Chip DRAM (via AXI)
        ↓
  Systolic Array Compute
